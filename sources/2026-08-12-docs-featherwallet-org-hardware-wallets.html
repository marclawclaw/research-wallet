Hardware wallets

Are hardware wallets supported?

Yes. Feather supports the following devices:

Ledger

  • Nano S
  • Nano S+
  • Nano X
  • Stax
  • Flex

Trezor

  • Model T
  • Safe 3
  • Safe 5

If you own a device that is advertised as having support for Monero and it is not listed above, please contact us.

For instructions on how to use your device with Feather see the following guide: Create a wallet (hardware device).
