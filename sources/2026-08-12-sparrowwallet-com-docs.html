    Connect to Bitcoin Core

    Make your wallet private by connecting Sparrow to your Bitcoin Core node using this guide.

    Setup a connected hardware wallet

    Use Sparrow with a Trezor, Ledger, BitBox02, Jade or other USB connected hardware wallet by following this guide.

    Setup an airgapped hardware wallet with QR codes

    Use Sparrow with a Passport, Jade, SeedSigner, Keystone, Krux or other airgapped hardware wallet using QR codes.

    Setup an airgapped hardware wallet with an SD card

    Secure your bitcoin by using Sparrow with a Coldcard, Keystone, Passport or other airgapped hardware wallet using an SD card.

    Setup an airgapped smartcard wallet

    Use Sparrow with a Tapsigner, Satschip, Satochip or Keycard smartcard by following this guide.

    Support

    As an open source project Sparrow Wallet does not have a support team. Instead, there is an active community-managed Telegram group: @SparrowWallet.

    Please be aware that there are many scammers on Telegram! The group admins (or “Sparrow support”) will not DM you.
